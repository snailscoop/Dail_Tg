CHEQD Telegram Bot - GunDB Server

Status: GunDB server is running

Server Information

This server provides a GunDB peer for the CHEQD Telegram Bot hackathon project.

API Endpoints

  • /gun - GunDB synchronization endpoint
  • /status - Server status endpoint

Test Connection

You can test the connection to the GunDB server using the following JavaScript code:

const gun = Gun('http://localhost:3000/gun');
const test = gun.get('test');
test.put({message: 'Hello World'});
test.on(data => console.log('Data:', data));
